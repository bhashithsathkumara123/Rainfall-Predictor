# Rainfall Prediction Using Machine Learning

A machine learning project developed in Python to predict rainfall using historical Australian weather data obtained from an Australian weather data source.

The project uses **NumPy** and **Pandas** for data processing and analysis, **Scikit-learn** to build and evaluate machine learning models, and **Matplotlib** for data visualization.

The main objective is to explore weather patterns, analyze historical meteorological data, and develop a predictive model capable of estimating the likelihood of rainfall based on weather-related features.

# Technologies Used:
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
